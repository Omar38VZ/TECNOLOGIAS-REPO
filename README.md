# Tecnologías para la Construcción de Software

Repositorio con los ejercicios de la materia: Programación Orientada a Objetos, principios SOLID y Patrones de Diseño. Cada tema está dividido por el compañero que presentó el código y, cuando aplica, en `Aplicado` / `NoAplicado`.

## Temario

- **Bloque 1:** Clases, clases abstractas e interfaces · Herencia simple y múltiple · Tipos de polimorfismo · SOLID (Single Responsibility, Open/Close, Liskov, Interface Segregation, Dependency Inversion)
- **Bloque 2:** Patrones de diseño creacionales: Singleton, Factory Method, Abstract Factory, Builder, Prototype, Object Pool
- **Bloque 3:** Patrones de diseño estructurales: Adapter, Decorator, Composite, Proxy, Facade, Bridge, Flyweight
